# PHASE 7: 本番環境へのリリースと検証

完成したシステムを本番環境へ安全にデプロイし、本番環境のアクセス権限・セキュリティ設定を自動検証してください。

## 作業手順

1. **最終矛盾チェック**:
   - `docs/` 配下の全設計書とソースコード間の不整合・誤植・不足を最終精査し、Artifacts に表示してください。

2. **本番適用作業手順書の作成**:
   - プラグインの `templates/本番適用作業手順書.md` を `docs/本番適用作業手順書.md` にコピー・配置してください。
   - 本プロジェクトのプロジェクトID、アプリケーションID、使用するGCPサービス、リージョンなどを確認し、手順書に反映させてください。
   - docs/配下のドキュメントを走査して内容を確認した上で、不足する要素は補完し、整合性を保ちながらdocs/本番適用作業手順書.mdを本プロジェクト用に最適化し、完成させてください。
   - 不明な点はユーザーに確認し、指示を得て手順書を完成させてください。

3. **ユーザーによる本番適用手順書の確認**:
   - 本番適用手順書をユーザーに提示し、最終確認・承認を得てください。
   - ユーザーからの修正指示があればこれに対応し、手順書を更新してください。
   - ユーザーが承認したら、本番適用作業手順書を確定し、次のステップへ進んでください。

4. **本番リリースの実行**:
   - `docs/本番適用手順書.md` に従って、本番環境の構築とデプロイを実行してください。

5. **本番環境セキュリティ設定の検証**:
   - デプロイ後、インフラ設定（Cloud Run Functions 等）のセキュリティを以下の通り自動検証・チェックリスト化してください：
     1. 認証の `IAM` および `IAP` が双方有効化されているか。
     2. Context-aware アクセスポリシー画面にて `Principal` 列に対象アクセスユーザー（メールアドレス）が正しく付与されているか。
     3. `AllUsers` アクセス権が適切に削除されているか。
   - 本番公開URLでの画面疎通テストおよび主要機能の動作検証を実施してください。
