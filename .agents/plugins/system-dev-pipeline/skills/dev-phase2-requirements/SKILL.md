# PHASE 2: 要件定義書の作成および清書

本スキルは、`docs/要件定義書.md` の精査・詳細化および清書を支援・自動実行します。

## 作業手順

1. **ドキュメントの読み込み**:
   - `docs/要件定義書.md` および `docs/` 配下の背景知識ドキュメントを読み込んでください。
2. **要件定義書の清書・構造化**:
   - 目的、システムの概要、機能要件、非機能要件、外部インターフェース要件、制約事項について漏れや抽象的な表現がないか検証し、具体的に清書してください。
3. **レビューと要確認項目の抽出**:
   - 曖昧な仕様やユーザー確認が必要な事項がある場合は、Artifactsに「要件定義確認事項」として出力してください。
4. **修正と確定**:
   - ユーザーのフィードバックに基づき `docs/要件定義書.md` を更新し、完了したら PHASE 3（基本設計）へ移行可能な状態にしてください。
