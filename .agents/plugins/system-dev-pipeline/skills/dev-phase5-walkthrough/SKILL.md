# PHASE 5: ウォークスルー後ドキュメント整備と同期

ウォークスルー（動作確認）完了後のソースコードを正として、`docs/` 配下のドキュメントの作成・整備および相互整合性の補正を行ってください。

## 作業手順

1. **ソースコード解析とバックエンドAPI仕様書の作成**:
   - ソースコードを解析し、以下のドキュメントを `docs/` 配下に作成してください。
     - `バックエンドAPI仕様書.md`

2. **ソースコードを正としたドキュメントの不整合・不足の補正**:
   - ソースコードの最新状態を正とし、`docs/` 配下の既存ドキュメントにおける矛盾や記述不足を洗い出して修正してください。

3. **ドキュメント間不整合の確認 (`dev-doc-reviewer`)**:
   - `dev-doc-reviewer` スキルを実行し、`docs/` 配下のドキュメント間の不整合を確認してください。

4. **検出された不整合の自動修復**:
   - 手順3で検出されたドキュメントの不整合を自動修復してください。
   - ただし、判断が必要な場合は処理を中断しユーザーに確認してください。

5. **反復実行制御（Self-Healing Loop）**:
   - 不整合がなくなるまで手順3〜4を反復実行してください。
   - ただし、**反復実行が5回を超えた時点で反復を中止**し、経過および未解消の課題をレポートとして出力した上で、ユーザーの指示を待ってください。
