# UIコンポーネントカタログ及び実装パターン (UI_COMPONENT_CATALOG)

## 1. 概要

本ドキュメントは、[01_グランドデザイン基本仕様書.md](./01_グランドデザイン基本仕様書.md) で定義されたデザインルールを、Web（React / Vue / Svelte / SSR / MPA）およびデスクトップ（Tauri / Electron / ネイティブ）環境において高品質かつ安全に実装するための「**クロスプラットフォームUIコンポーネント標準実装カタログ**」である。

AIエージェント（`ui-designer`, `backend-engineer`）は、画面コンポーネントを実装する際、本カタログに掲載されたクラス設計・アクセシビリティ対応・ドラッグ領域分離・ストレージアダプター・モックアップ制御規約に厳格に準拠すること。

## 2. 他フレームワーク・マルチプラットフォーム置換マッピング

React (TSX) 以外の技術スタックを採用する場合、以下のマッピング表に準拠して等価なコンポーネント・構文に置き換える。

| 機能要素 | React (TSX) 標準 | Vue 3 / Nuxt 3 | Svelte 5 / SvelteKit | MPA + HTMX / Alpine.js |
| :--- | :--- | :--- | :--- | :--- |
| **オーバーレイマウント** | `createPortal(..., document.body)` | `<Teleport to="body">` | `use:portal` アクション | body直下固定DOM / Alpine `x-teleport` |
| **ルーターリンク** | `react-router-dom: NavLink` | `<RouterLink active-class="...">` / `<NuxtLink>` | `<a href="..." class:active={...}>` | 標準 `<a>` タグ + サーバー側判定 |
| **アイコンライブラリ** | `lucide-react` | `lucide-vue-next` | `lucide-svelte` | インラインSVG / SVGスプライト |
| **リアクティビティ** | `useState`, `useEffect` | `ref`, `computed`, `watch` | `$state`, `$derived`, `$effect` | Alpine.js `x-data` / HTMX 属性 |
| **デスクトップドラッグ** | `data-tauri-drag-region` | 同左 | 同左 | 同左（HTML属性共通） |

### 3.2 デスクトップ用カスタムタイトルバー（`TitleBar.tsx`）

Frameless Window を採用する PC デスクトップアプリ（Tauri / Electron）専用のタイトルバー。OSネイティブ操作ボタンとの干渉を防ぐセーフエリア、およびドラッグ領域・非ドラッグ領域の分離を内包する。

```tsx
import React from 'react';
import { Minus, Square, X } from 'lucide-react';

interface TitleBarProps {
  title?: string;
  version?: string;
  platform?: 'macos' | 'windows' | 'linux';
  onMinimize?: () => void;
  onMaximize?: () => void;
  onClose?: () => void;
}

export const TitleBar: React.FC<TitleBarProps> = ({
  title = 'デスクトップシステム',
  version = '1.0',
  platform = 'windows',
  onMinimize,
  onMaximize,
  onClose,
}) => {
  const isMac = platform === 'macos';

  return (
    <div
      data-tauri-drag-region
      style={{ WebkitAppRegion: 'drag' } as React.CSSProperties}
      className={`h-10 select-none bg-white dark:bg-slate-900 border-b border-slate-200 dark:border-slate-800 flex items-center justify-between text-xs z-50 ${
        isMac ? 'pl-20 pr-4' : 'pl-4 pr-0'
      }`}
    >
      {/* ロゴ & タイトル表示領域（ドラッグ可能） */}
      <div className="flex items-center gap-2">
        <span className="font-bold text-slate-800 dark:text-slate-200">{title}</span>
        <span className="text-[10px] font-mono px-1.5 py-0.5 rounded bg-slate-100 dark:bg-slate-800 text-slate-500 border border-slate-200 dark:border-slate-700">
          v{version}
        </span>
      </div>

      {/* 中央ドラッグ領域 */}
      <div className="flex-1 h-full" data-tauri-drag-region />

      {/* Windows / Linux ウィンドウ操作ボタン群（非ドラッグ領域: no-drag必須） */}
      {!isMac && (
        <div
          data-tauri-drag-region="false"
          style={{ WebkitAppRegion: 'no-drag' } as React.CSSProperties}
          className="flex items-center h-full"
        >
          <button
            onClick={onMinimize}
            title="Minimize"
            aria-label="最小化"
            className="w-11 h-full flex items-center justify-center text-slate-600 dark:text-slate-400 hover:bg-slate-200 dark:hover:bg-slate-800 transition"
          >
            <Minus className="w-3.5 h-3.5" />
          </button>
          <button
            onClick={onMaximize}
            title="Maximize"
            aria-label="最大化"
            className="w-11 h-full flex items-center justify-center text-slate-600 dark:text-slate-400 hover:bg-slate-200 dark:hover:bg-slate-800 transition"
          >
            <Square className="w-3 h-3" />
          </button>
          <button
            onClick={onClose}
            title="Close"
            aria-label="閉じる"
            className="w-12 h-full flex items-center justify-center text-slate-600 dark:text-slate-400 hover:bg-rose-600 hover:text-white transition"
          >
            <X className="w-4 h-4" />
          </button>
        </div>
      )}
    </div>
  );
};
```

```tsx
import React, { useState } from 'react';
import { Home, Folder, BarChart2, Settings, ChevronLeft, ChevronRight } from 'lucide-react';

interface SidebarItem {
  id: string;
  label: string;
  icon: React.ComponentType<{ className?: string }>;
  active?: boolean;
}

interface CollapsibleSidebarProps {
  activeId: string;
  onSelect: (id: string) => void;
}

export const CollapsibleSidebar: React.FC<CollapsibleSidebarProps> = ({ activeId, onSelect }) => {

    { id: 'items', label: 'データ一覧', icon: Folder },
    { id: 'analytics', label: '可視化・分析', icon: BarChart2 },

  return (
    <aside
      className={`h-full bg-white dark:bg-slate-800 border-r border-slate-200 dark:border-slate-700 flex flex-col justify-between transition-all duration-200 select-none ${
        isCollapsed ? 'w-16' : 'w-60'

    >
      <div className="p-3">
        {/* トグルボタン */}
        <div className="flex justify-end mb-4">
          <button
            onClick={() => setIsCollapsed(!isCollapsed)}
            title={isCollapsed ? 'Expand Sidebar' : 'Collapse Sidebar'}
            className="p-1.5 rounded-lg text-slate-400 hover:text-slate-600 dark:hover:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-700 transition"

            {isCollapsed ? <ChevronRight className="w-4 h-4" /> : <ChevronLeft className="w-4 h-4" />}

        {/* ナビゲーションリスト */}

            const Icon = item.icon;
            const isActive = activeId === item.id;
            return (
              <button
                key={item.id}
                onClick={() => onSelect(item.id)}
                title={isCollapsed ? item.label : undefined}
                className={`w-full flex items-center gap-3 px-3 py-2.5 rounded-xl text-sm font-medium transition ${

                    : 'text-slate-700 dark:text-slate-300 hover:bg-slate-100 dark:hover:bg-slate-700/50'

              >
                <Icon className="w-5 h-5 flex-shrink-0" />
                {!isCollapsed && <span className="truncate">{item.label}</span>}
              </button>
            );
          })}
        </nav>
      </div>

      {/* フッター情報 */}
      {!isCollapsed && (
        <div className="p-4 border-t border-slate-200 dark:border-slate-700 text-xs text-slate-400">
          ショートカット: <kbd className="font-mono bg-slate-100 dark:bg-slate-900 px-1 py-0.5 rounded">Ctrl+,</kbd>
```

### 3.4 リサイザブル・スプリットペイン（`SplitPane.tsx`）

一覧と詳細を左右に並べ、マウスドラッグで比率を可変調整できるデスクトップ必須コンポーネント。

```tsx
import React, { useState, useRef, useCallback } from 'react';

interface SplitPaneProps {
  left: React.ReactNode;
  right: React.ReactNode;
  defaultLeftWidth?: number; // 初期左ペイン幅 (px)
  minLeftWidth?: number;     // 最小左ペイン幅 (px)
  maxLeftWidth?: number;     // 最大左ペイン幅 (px)
}

export const SplitPane: React.FC<SplitPaneProps> = ({
  left,
  right,
  defaultLeftWidth = 320,
  minLeftWidth = 220,
  maxLeftWidth = 600,
}) => {
  const [leftWidth, setLeftWidth] = useState(defaultLeftWidth);
  const isDragging = useRef(false);

  const onMouseDown = useCallback(() => {
    isDragging.current = true;
    document.body.style.cursor = 'col-resize';
    document.body.style.userSelect = 'none';

    const onMouseMove = (e: MouseEvent) => {
      if (!isDragging.current) return;
      const newWidth = Math.min(Math.max(e.clientX, minLeftWidth), maxLeftWidth);
      setLeftWidth(newWidth);
    };

    const onMouseUp = () => {
      isDragging.current = false;
      document.body.style.cursor = '';
      document.body.style.userSelect = '';
      window.removeEventListener('mousemove', onMouseMove);
      window.removeEventListener('mouseup', onMouseUp);
    };

    window.addEventListener('mousemove', onMouseMove);
    window.addEventListener('mouseup', onMouseUp);
  }, [minLeftWidth, maxLeftWidth]);

  return (
    <div className="flex w-full h-full overflow-hidden">
      {/* 左ペイン */}
      <div style={{ width: leftWidth }} className="h-full flex-shrink-0 overflow-y-auto">
        {left}
      </div>

      {/* スプリッター境界線 */}
      <div
        onMouseDown={onMouseDown}
        onDoubleClick={() => setLeftWidth(defaultLeftWidth)}
        title="ドラッグで幅変更 / ダブルクリックでリセット"
        className="w-1.5 h-full cursor-col-resize bg-slate-200 dark:bg-slate-700 hover:bg-blue-500 dark:hover:bg-blue-500 transition-colors flex-shrink-0"
      />

      {/* 右ペイン */}
      <div className="flex-1 h-full overflow-y-auto min-w-0 bg-slate-50 dark:bg-slate-900">
        {right}
      </div>
    </div>
  );
};
```

### 3.6 右スライドイン ハンバーガーメニュー（`HamburgerMenu.tsx`）

```tsx
import React, { useEffect } from 'react';
import { createPortal } from 'react-dom';
import { Home, Folder, BarChart2, Settings, X, Sun, Moon, Monitor, LogOut, User } from 'lucide-react';

interface HamburgerMenuProps {
  isOpen: boolean;
  onClose: () => void;
  theme: 'light' | 'dark' | 'system';
  setTheme: (mode: 'light' | 'dark' | 'system') => void;
  systemName?: string;
}

export const HamburgerMenu: React.FC<HamburgerMenuProps> = ({
  isOpen,
  onClose,
  theme,
  setTheme,
  systemName = 'システム名称',
}) => {
  useEffect(() => {
    if (!isOpen) return;

    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose();
    };

    document.addEventListener('keydown', handleKeyDown);
    const originalOverflow = document.body.style.overflow;
    document.body.style.overflow = 'hidden';

    return () => {
      document.removeEventListener('keydown', handleKeyDown);
      document.body.style.overflow = originalOverflow;
    };
  }, [isOpen, onClose]);

  if (!isOpen) return null;

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex justify-end bg-black/40 backdrop-blur-sm transition-opacity"
      onClick={onClose}
      role="dialog"
      aria-modal="true"
      aria-label="ナビゲーションメニュー"
    >
      <div
        className="w-80 h-full bg-white dark:bg-slate-800 p-6 shadow-2xl flex flex-col justify-between overflow-y-auto transform transition-transform duration-200 ease-in-out"
        onClick={(e) => e.stopPropagation()}
      >
        <div>
          <div className="flex items-center justify-between pb-4 mb-6 border-b border-slate-200 dark:border-slate-700">
            <h2 className="text-xl font-bold bg-gradient-to-r from-blue-600 to-indigo-600 bg-clip-text text-transparent">
              {systemName}
            </h2>
            <button
              onClick={onClose}
              title="Close"
              aria-label="メニューを閉じる"
              className="p-2 rounded-lg text-slate-500 hover:text-slate-700 dark:text-slate-400 dark:hover:text-slate-200 hover:bg-slate-100 dark:hover:bg-slate-700 transition"
            >
              <X className="w-5 h-5" />
            </button>
          </div>

          <nav className="space-y-2">
            {[
              { to: '/', label: 'ダッシュボード', icon: Home },
              { to: '/items', label: 'データ一覧', icon: Folder },
              { to: '/analytics', label: '可視化・分析', icon: BarChart2 },
              { to: '/master', label: 'マスタ管理', icon: Settings },
            ].map((link) => {
              const Icon = link.icon;
              return (
                <a
                  key={link.to}
                  href={link.to}
                  onClick={onClose}
                  className="flex items-center gap-3 px-4 py-3 rounded-lg text-sm font-medium text-slate-700 dark:text-slate-300 hover:bg-slate-100 dark:hover:bg-slate-700/50 transition"
                >
                  <Icon className="w-5 h-5 text-slate-500 dark:text-slate-400" />
                  <span>{link.label}</span>
                </a>
              );
            })}
          </nav>
        </div>

        <div className="pt-6 border-t border-slate-200 dark:border-slate-700 space-y-5">
          <div>
            <label className="text-xs font-semibold text-slate-500 dark:text-slate-400 block mb-2">
              外観テーマ設定
            </label>
            <div className="grid grid-cols-3 gap-2 p-1 bg-slate-100 dark:bg-slate-900 rounded-xl">
              {[
                { mode: 'light', label: 'Light', icon: Sun },
                { mode: 'dark', label: 'Dark', icon: Moon },
                { mode: 'system', label: 'Auto', icon: Monitor },
              ].map((item) => {
                const Icon = item.icon;
                const isSelected = theme === item.mode;
```

## 4. リアルタイム検索バー（デバウンス + サジェストドロップダウン）

WebリモートAPI用のデバウンス（250ms）と、ローカルデータ用の即時検索（`immediate` フラグ）の両モードに対応。

```tsx
import React, { useState, useEffect, useRef } from 'react';
import { Search, X, Loader2 } from 'lucide-react';

interface SuggestionItem {
  id: string;
  title: string;
  category?: string;
}

interface RealtimeSearchProps {
  onSearch: (query: string) => void;
  onSelectSuggestion?: (item: SuggestionItem) => void;
  fetchSuggestions?: (query: string) => Promise<SuggestionItem[]>;
  placeholder?: string;
  debounceMs?: number; // ローカルDB時は 0 または 50 を指定
}

export const RealtimeSearch: React.FC<RealtimeSearchProps> = ({
  onSearch,
  onSelectSuggestion,
  fetchSuggestions,
  placeholder = 'キーワード、ID、名称で高速検索...',
  debounceMs = 250,
}) => {
  const [query, setQuery] = useState('');
  const [suggestions, setSuggestions] = useState<SuggestionItem[]>([]);
  const [isLoading, setIsLoading] = useState(false);
  const [isOpen, setIsOpen] = useState(false);
  const wrapperRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const handler = setTimeout(async () => {
      onSearch(query);
      if (query.trim().length > 0 && fetchSuggestions) {
        setIsLoading(true);
        try {
          const results = await fetchSuggestions(query);
          setSuggestions(results);
          setIsOpen(results.length > 0);
        } catch (error) {
          console.error(error);
        } finally {
          setIsLoading(false);
        }
      } else {
        setSuggestions([]);
        setIsOpen(false);
      }
    }, debounceMs);

    return () => clearTimeout(handler);
  }, [query, debounceMs, onSearch, fetchSuggestions]);

  useEffect(() => {
    const handleClickOutside = (e: MouseEvent) => {
      if (wrapperRef.current && !wrapperRef.current.contains(e.target as Node)) {
        setIsOpen(false);
      }
    };
    document.addEventListener('mousedown', handleClickOutside);
    return () => document.removeEventListener('mousedown', handleClickOutside);
  }, []);

  return (
    <div ref={wrapperRef} className="relative w-full max-w-2xl">
      <div className="relative flex items-center">
        <Search className="absolute left-4 w-5 h-5 text-slate-400 pointer-events-none" />
        <input
          type="text"
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          onFocus={() => query.trim().length > 0 && suggestions.length > 0 && setIsOpen(true)}
          placeholder={placeholder}
          className="w-full pl-11 pr-10 py-3 rounded-2xl bg-white/90 dark:bg-slate-800/90 border border-slate-200 dark:border-slate-700 text-slate-900 dark:text-slate-100 text-sm placeholder:text-slate-400 focus:outline-none focus:ring-2 focus:ring-blue-500 shadow-sm"
        />
        {isLoading && <Loader2 className="absolute right-10 w-4 h-4 text-blue-500 animate-spin" />}
        {query && (
          <button
            onClick={() => {
              setQuery('');
              onSearch('');
            }}
            title="Clear"
            className="absolute right-3 p-1 rounded-full text-slate-400 hover:text-slate-600"
          >
            <X className="w-4 h-4" />
          </button>
        )}
      </div>

      {isOpen && suggestions.length > 0 && (

      )}

  );
};
```

## 5. ストレージアダプター層（`IStorageAdapter`）

ブラウザの `localStorage` への直接依存を排除し、WebとPCデスクトップ（Tauri Store / 設定ファイル）で透過的に切り替えるための標準インターフェース。

```typescript
export interface IStorageAdapter {
  getItem<T>(key: string, defaultValue?: T): Promise<T | null>;
  setItem<T>(key: string, value: T): Promise<void>;
  removeItem(key: string): Promise<void>;
}

// Webブラウザ用 LocalStorage 実装
export class BrowserStorageAdapter implements IStorageAdapter {
  async getItem<T>(key: string, defaultValue?: T): Promise<T | null> {
    const raw = localStorage.getItem(key);
    if (raw === null) return defaultValue ?? null;
    try {
      return JSON.parse(raw) as T;
    } catch {
      return (raw as unknown) as T;
    }
  }

  async setItem<T>(key: string, value: T): Promise<void> {
    const str = typeof value === 'string' ? value : JSON.stringify(value);
    localStorage.setItem(key, str);
  }

  async removeItem(key: string): Promise<void> {
    localStorage.removeItem(key);
  }
}

// Tauri用 Store アダプター実装（デスクトップ永続化）
export class TauriStorageAdapter implements IStorageAdapter {
  // @tauri-apps/plugin-store 等を用いてローカル config.json へ書き込む
  async getItem<T>(key: string, defaultValue?: T): Promise<T | null> {
    // Tauri Store 経由での取得ロジック
    return defaultValue ?? null;
  }

  async setItem<T>(key: string, value: T): Promise<void> {
    // Tauri Store 経由での永続化ロジック
  }

  async removeItem(key: string): Promise<void> {
    // Tauri Store 経由での削除ロジック
  }
}
```

## 6. リポジトリ抽象化とモック切り替えパターン

コンポーネント内への直書きモックを禁止し、環境変数で実APIとモックを安全に切り替える定型パターン。

```typescript
// 1. リポジトリインターフェース
export interface Item {
  id: string;
  name: string;
  status: 'active' | 'completed';
}

export interface IItemRepository {
  getItems(): Promise<Item[]>;
  saveItem(item: Item): Promise<void>;
}

// 2. 本番用リポジトリ (HTTP fetch または Tauri IPC invoke)
export class HttpItemRepository implements IItemRepository {
  async getItems(): Promise<Item[]> {
    const res = await fetch('/api/items');
    return res.json();
  }
  async saveItem(item: Item): Promise<void> {
    await fetch('/api/items', { method: 'POST', body: JSON.stringify(item) });
  }
}

// 3. 開発・テスト用 MockRepository (デスクトップ等 MSWが使えない環境用)
export class MockItemRepository implements IItemRepository {
  private items: Item[] = [
    { id: '1', name: 'モックデータA', status: 'active' },

  ];

    return [...this.items];
  }
  async saveItem(item: Item): Promise<void> {
    this.items.push(item);
  }
}

// 4. ファクトリ / DI関数
export function createItemRepository(): IItemRepository {
  if (import.meta.env.VITE_ENABLE_MOCK === 'true') {
```

## 8. 標準モーダル（簡易入力用中央ポップアップ）

```tsx
import React, { useEffect } from 'react';
import { createPortal } from 'react-dom';
import { X, Loader2 } from 'lucide-react';

interface StandardModalProps {
  isOpen: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
  onConfirm?: () => Promise<void> | void;
  confirmLabel?: string;
  cancelLabel?: string;
  isLoading?: boolean;
}

export const StandardModal: React.FC<StandardModalProps> = ({
  isOpen,
  onClose,
  title,
  children,
  onConfirm,
  confirmLabel = 'Save Changes',
  cancelLabel = 'Close',
  isLoading = false,
}) => {
  useEffect(() => {
    if (!isOpen) return;
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose();
    };
    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }, [isOpen, onClose]);

  if (!isOpen) return null;

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/50 backdrop-blur-sm"
      onClick={onClose}
      role="dialog"
      aria-modal="true"
    >
      <div
        className="w-full max-w-lg bg-white dark:bg-slate-800 rounded-2xl shadow-2xl p-6 border border-slate-200 dark:border-slate-700 space-y-6"
        onClick={(e) => e.stopPropagation()}
      >
        <div className="flex items-center justify-between pb-3 border-b border-slate-100 dark:border-slate-700">
          <h3 className="text-lg font-bold text-slate-900 dark:text-white">{title}</h3>
          <button onClick={onClose} title="Close" className="p-1 rounded-lg text-slate-400 hover:text-slate-600">
            <X className="w-5 h-5" />
          </button>
        </div>

        <div className="text-sm text-slate-700 dark:text-slate-300">{children}</div>

        <div className="flex items-center justify-end gap-3 pt-3 border-t border-slate-100 dark:border-slate-700">
          <button
            onClick={onClose}
            disabled={isLoading}
            className="px-4 py-2 rounded-xl text-sm font-medium bg-slate-100 dark:bg-slate-700 text-slate-700 dark:text-slate-200 hover:bg-slate-200"
          >
            {cancelLabel}
          </button>
          {onConfirm && (
            <button
              onClick={onConfirm}
              disabled={isLoading}
              className="px-5 py-2 rounded-xl text-sm font-medium bg-blue-600 hover:bg-blue-700 text-white shadow-sm flex items-center gap-2 disabled:opacity-50"
            >
              {isLoading && <Loader2 className="w-4 h-4 animate-spin" />}
              <span>{confirmLabel}</span>
            </button>
          )}
        </div>
      </div>
    </div>,
    document.body
  );
};
```

## 9. インライン編集コンポーネント（直接編集）

```tsx
import React, { useState } from 'react';
import { Pencil, Check, X, Loader2 } from 'lucide-react';

interface InlineTextEditProps {
  value: string;
  onSave: (newValue: string) => Promise<void>;
  placeholder?: string;
  textClassName?: string;
}

export const InlineTextEdit: React.FC<InlineTextEditProps> = ({
  value,
  onSave,
  placeholder = 'テキストを入力...',
  textClassName = 'text-xl font-bold text-slate-900 dark:text-white',
}) => {
  const [isEditing, setIsEditing] = useState(false);
  const [currentVal, setCurrentVal] = useState(value);
  const [saving, setSaving] = useState(false);

  const handleStart = () => {
    setCurrentVal(value);
    setIsEditing(true);
  };

  const handleCancel = () => {
    setIsEditing(false);
    setCurrentVal(value);
  };

  const handleSave = async () => {
    if (!currentVal.trim() || currentVal === value) {
      setIsEditing(false);
      return;
    }
    setSaving(true);
    try {
      await onSave(currentVal.trim());
      setIsEditing(false);
    } catch (err) {
      console.error(err);
    } finally {
      setSaving(false);
    }
  };

  if (isEditing) {
    return (
      <div className="flex items-center gap-2">
        <input
          type="text"
          value={currentVal}
          onChange={(e) => setCurrentVal(e.target.value)}
          placeholder={placeholder}
          disabled={saving}
          autoFocus
          className="px-3 py-1.5 rounded-xl border border-blue-400 bg-white dark:bg-slate-900 text-sm focus:outline-none focus:ring-2 focus:ring-blue-500"
        />
        <button
          onClick={handleSave}
          disabled={saving}
          title="Save Changes"
          className="p-1.5 rounded-lg bg-emerald-600 hover:bg-emerald-700 text-white transition disabled:opacity-50"
        >
          {saving ? <Loader2 className="w-4 h-4 animate-spin" /> : <Check className="w-4 h-4" />}
        </button>
        <button
          onClick={handleCancel}
          disabled={saving}
          title="Close"
          className="p-1.5 rounded-lg border border-slate-200 dark:border-slate-700 text-slate-500 hover:bg-slate-100 transition disabled:opacity-50"
        >
          <X className="w-4 h-4" />
        </button>
      </div>
    );
  }

  return (
    <div
      onClick={handleStart}
      className="group inline-flex items-center gap-2 cursor-pointer rounded-lg px-2 py-1 -ml-2 hover:bg-slate-100 dark:hover:bg-slate-800 transition"
      title="Click to edit"
    >
      <span className={textClassName}>{value || placeholder}</span>
      <Pencil className="w-4 h-4 text-slate-400 opacity-0 group-hover:opacity-100 transition" />
    </div>
  );
};
```
