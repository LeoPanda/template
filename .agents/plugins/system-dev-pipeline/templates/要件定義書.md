## 2. システムの機能

### 2.1 ダッシュボード機能

- システム主要データのサマリー表示、視覚的なインジケーター/グラフィック、および直近のアクティビティを把握できるようにします。

### 2.2 検索機能

- 管理対象および各種マスターデータを、キーワード（名称、概要、備考等）によってリアルタイムに絞り込み・検索できる機能を備えます。

### 2.3 マスタ管理機能

- 各種区分・分類等のマスタデータを画面から登録・編集・削除可能とします。

### 2.4 一覧画面機能

- 各種データの一覧画面を設け、ページネーション表示、ソート機能、および詳細表示/編集モーダルとの連携を提供します。

## 3. 技術要件・認証・バックアップ構成

- **認証・アクセス制御**: 本システムは Cloud Run の Identity-Aware Proxy (IAP) により、ログイン認証およびアクセス制限を行います。
- **データベースバックアップ前提**: 本番環境で SQLite を運用する際、Litestream による GCS へのレプリケーションバックアップを行います。
  - **最大インスタンス数制限**: 複数コンテナによる Litestream 書き込み衝突を防ぐため、Cloud Run の最大インスタンス数を `max-instances=1` に制限設定します。
  - **バックアップ用バケット名ユニーク化**: 同一 GCP プロジェクト上で複数のサービスを稼働させるため、バックアップ用 GCS バケット名には Docker コンテナ名を入れてユニーク化を図ります。
- その他、技術要件の詳細については別途 [技術要件定義書.md](file:///Users/sakyo/Documents/workspace/AI/template/doc_samples/%E6%8A%80%E8%A1%93%E8%A6%81%E4%BB%B6%E5%AE%9A%E7%BE%A9%E6%9B%B8.md) を参照のこと。

## 4. 共通 UI/UX ・レスポンシブ・インタラクション仕様

### 4.1 デバイス別ブレークポイント (Tailwind CSS)

- **モバイル表示（スマートフォン・狭画面端末）**: 画面幅 767px 以下（Tailwind CSS の `md:` 未満）
- **デスクトップ表示（PC・タブレット広画面）**: 画面幅 768px 以上。メインコンテナの最大幅を 1800px に拡大（`max-w-[1800px]`）

### 4.2 ハンバーガーメニュー方式

- **基本設計**: トップバー画面右端にハンバーガーメニューを設け、他ページやマスタメンテナンス等のリンクはメニュー内に配置します。

### 4.3 テーマ切り替え機能（マルチテーマ: ライト／ダーク／OS設定追従）

- **基本設計**: 「ライトモード」「ダークモード」「システム (OS設定追従)」の 3 つの表示モード切替をサポートします。
- **UI配置**: ナビゲーションバー右側およびハンバーガーメニュー最下部にテーマモード選択ボタンを配置し、OSのダークモード設定変更（`prefers-color-scheme: dark`）へのリアルタイム自動連動を提供します。

### 4.4 ボタン類のミニマルアイコン化および英語表記ルール

- すべての操作ボタンの機能説明（tooltip / title 属性）は英語表記で統一します。
- 操作が明確な機能（Edit, Delete, Search など）のボタンはアイコンのみのミニマル表示とします。
