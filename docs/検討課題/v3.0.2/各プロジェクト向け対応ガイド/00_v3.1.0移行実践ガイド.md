## 1. 移行の背景と目的

`system-dev-pipeline` v3.0.1 では、ASTトートロジー排除やモック排除、署名付き証跡（`qa_runtime_evidence.json`）が導入されました。
しかし、実践プロジェクト（Movie Log 等）において、**テストフィクスチャ（`conftest.py`）内で環境変数を書き換えてホストOSとコンテナのパス差異を隠蔽（マスキング）し、全テストをパスした後に実機提示（REV-4）で主要APIが 500 エラーで全滅する**という致命的インシデントが発生しました。

個別禁止ルールのイタチごっこを脱却し、**「ブラックボックス実動不変条件（Live Invariant Probe）」**と**「環境適応耐性（Core-Absorbed Resilience）」**を既存プロジェクトへ導入することで、実機提示前の 100% 決定論的稼働保証を実現します。

### Step 2: `Smart Database URL & Path Resolver` のバックエンド配備
ホストOSとDockerコンテナ間のパス乖離（`/app/data` 等）をテスト側ではなく**本体コード自身が自動解決**するようにします。

`backend/app/core/config.py`（または `core/config.py`）に以下のリゾルバを配備します：

```python
from pathlib import Path
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    DATABASE_URL: str = "sqlite:////app/data/app.db"

    @property
    def resolved_database_url(self) -> str:
        """コンテナ絶対パス不在時にローカル data/ へ安全に自己フォールバックし、親ディレクトリを自動生成する"""
        if self.DATABASE_URL.startswith("sqlite:////"):
            raw_path = Path(self.DATABASE_URL.replace("sqlite:////", "/"))
            if not raw_path.parent.exists():
                local_data = Path.cwd() / "data"
                local_data.mkdir(parents=True, exist_ok=True)
                return f"sqlite:///{local_data / raw_path.name}"
            raw_path.parent.mkdir(parents=True, exist_ok=True)
        return self.DATABASE_URL
```

DBエンジン生成部（`db/session.py` 等）は、`settings.resolved_database_url` を参照するように統一します。

### Step 3: FastAPI `lifespan` Fail-Fast DB 接続チェック & Deep Health Probe
起動シーケンス初期に DB 接続を強制検証し、未接続やパーミッション不正時に即時例外停止させます。また、`/api/health?deep=true` エンドポイントを配備します。

`backend/core/main.py`:
```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from sqlalchemy import text
from core.db import engine

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 起動時フェイルファスト検証
    with engine.connect() as conn:
        conn.execute(text("SELECT 1"))
    yield

app = FastAPI(lifespan=lifespan)
```

`backend/api/internal/health.py`:
```python
from fastapi import APIRouter, Query, Response, status
from sqlalchemy import text
from core.db import engine

router = APIRouter()

@router.get("/health")
def health_check(deep: bool = Query(False), response: Response = None):
    res = {"status": "healthy"}
    if deep:
        try:
            with engine.connect() as conn:
                conn.execute(text("SELECT 1"))
            res["database"] = "connected"
        except Exception as e:
            if response:
                response.status_code = status.HTTP_500_INTERNAL_SERVER_ERROR
            return {"status": "unhealthy", "database": str(e)}
    return res
```

### Step 4: テストフィクスチャ（`conftest.py`）のマスキングコード撤去
`tests/conftest.py` 等で環境変数 `os.environ["DATABASE_URL"]` を書き換えていたコードを**完全に削除**します。
本体コード自身の `Smart Database URL & Path Resolver` により、書き換えなしでホストOS上のテストが正常通過することを確認します。
