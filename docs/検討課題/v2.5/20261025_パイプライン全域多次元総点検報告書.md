## 3. 残余検討課題とインサイト

### 3.1 `sync_pipeline.sh` のコード規模について
- **現状**: `.agents/skills/template-pipeline-sync/scripts/sync_pipeline.sh` は 492 行。
- **評価**: 本スクリプトは配布プラグインのランタイムコードではなく、template リポジトリ開発者用のメタ運用ツールです。現在正常に稼働しており（sha256sum/shasum フォールバック対応済み）、直ちに障害を引き起こすリスクはありません。
- **今後の推奨**: V2.6 以降の保守性向上のため、埋め込まれている Python インラインスクリプト（ルール共通部・固有部分離、ツリーハッシュ計算等）を独立モジュールへ外出しすることを推奨課題として記録します。
